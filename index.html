🏥 Информационная система «Поликлиника»

Полнофункциональный программный комплекс для амбулаторно-поликлинических учреждений (Демоэкзамен, Вариант № 2). Автоматизация регистратуры, электронная медкарта, система лояльности и планирование закупок медикаментов.

✓ Модуль 1: База данных (3NF, ER-диаграмма, SQL) ✓ Модуль 2: Алгоритм индивидуальной скидки (0%-15%) ✓ Модуль 3: WPF интерфейс и валидация ✓ Модуль 4: Интеграция с поставщиками и расчет лекарств ✓ 37 автоматизированных тестов xUnit

🚀 Запуск готового настольного приложения (Desktop WPF)

Для запуска полноценной десктопной версии системы на компьютере клиента подготовлен файл в один клик:

C:\Вариант 2\Запустить_Поликлиника.bat

Приложение не требует настройки СУБД или прав администратора — локальная база данных SQLite развертывается и инициализируется на лету.
